An offline guide and tracker for all 55 GTA 6 trophies on PlayStation 5: a checklist that saves in the browser, a 7-stage roadmap to the platinum, an honest missables list, and a guide in our own words for every trophy — each one citing its source. The game launched the day this ledger was built, so where no guide had confirmed a trigger yet, the guide says so instead of guessing.

What it does: tick trophies off and they stay ticked (localStorage); export your progress to JSON and import it back; filter by kind (story, missable, collectibles, activities, online), grade, search or earned-only; hide story spoilers until a trophy is earned; open any trophy for its guide, its source and its roadmap stage. No online trophies exist, and the app itself makes no network request — it runs with the network off.

## Run it

```sh
node serve.ts
```
(lalu buka http://localhost:8080 di desktop Chrome; centang trophy, buka tab Roadmap to Platinum, Missables, atau Sources & honesty)
